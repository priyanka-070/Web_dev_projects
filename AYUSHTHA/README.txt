AYUSHTHA.COM FRONTEND
======================
1. Open this folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click index.html -> Open with Live Server.
4. Explore Home, Shop, Products, Cart, Checkout and Payment.

This is a FRONTEND DEMO. Cart, wishlist, account and orders use browser localStorage.
The payment page simulates payment/order confirmation. For real payments, connect a secure backend/payment gateway.
